# Layne · 26 anos

Site de aniversário inspirado em Death Note: caderno 3D que abre e escreve as regras letra por letra, silhueta do Ryuk, chuva de maçãs e um vídeo de homenagem. HTML, CSS e JavaScript puros, sem build.

## Estrutura

```
index.html        página inteira (estilos e scripts incluídos)
assets/           imagem de fundo, poster e vídeo
```

## Ver no computador

Abra o `index.html` no navegador.

## Publicar no GitHub Pages

1. Crie um repositório e envie estes arquivos para a branch `main`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Em alguns minutos o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

## Personalizar

- As seis regras estão na constante `RULES`, no fim do `index.html`.
- Para trocar o vídeo, substitua `assets/henrique-lany.mp4` e `assets/poster.jpg`.

## Atenção

Em repositório público, o vídeo e o nome ficam visíveis para qualquer pessoa. Se preferir, deixe o repositório privado ou tire o vídeo antes de publicar.
